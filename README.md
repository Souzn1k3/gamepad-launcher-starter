# Gamepad Launcher Starter

Фоновая программа для Windows, которая запускает выбранные приложения при подключении геймпада к ПК. По умолчанию это Steam и Epic Games; Discord и любые другие программы добавляются в настройках.

Работает в трее, не требует администратора, ничего не закрывает при отключении геймпада.

## Возможности

- Определение любого геймпада: Xbox, DualSense, DualShock 4, 8BitDo, generic HID.
- Подключение по USB и по Bluetooth.
- Список приложений с индивидуальными настройками:
  - включено/выключено;
  - путь к `.exe` (автоопределение для Steam, Epic Games, Discord);
  - аргументы обычного и свёрнутого запуска;
  - имя процесса для проверки «уже запущено»;
  - режим запуска: обычное окно или свёрнуто;
  - разворачивать ли окно уже работающего приложения.
- Пресеты Steam, Epic Games, Discord и кнопка «Добавить приложение» для любых других программ.
- Частичный запуск: по умолчанию запускаются только отсутствующие приложения. Можно выбрать «ничего не делать, если хотя бы одно выбранное уже работает».
- Режим «Только трей»: геймпад определяется, уведомление показывается, приложения не запускаются.
- Уведомления в трее можно полностью отключить; все события остаются в журнале.
- Автозапуск программы при входе в Windows.
- Запуск приложений, если геймпад уже подключён в момент старта программы.
- Опциональный пропуск запуска, если активно полноэкранное приложение (по умолчанию выключен).
- Список игнорируемых геймпадов.
- Steam убирается из автозапуска Windows с резервной копией и возможностью восстановления.
- Журнал и диагностика.

## Сборка

Требования: Windows 10/11, .NET Framework 4.8 (уже есть в Windows), компилятор `csc.exe` (Roslyn из Visual Studio 2022 или встроенный Framework-компилятор).

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Результат: `dist\GamepadLauncherStarter.exe`.

## Установка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Скрипт копирует программу в `%LOCALAPPDATA%\Programs\GamepadLauncherStarter`, создаёт ярлык в меню «Пуск» и запускает её. При первом запуске открывается окно настроек.

Можно запускать и напрямую из `dist\GamepadLauncherStarter.exe`. В этом случае автозапуск будет указывать на папку `dist`; не перемещайте её после включения автозапуска. Если всё же переместили — запустите `.exe` по новому пути, и запись автозапуска обновится.

## Первый запуск

1. Создаются настройки: `%LOCALAPPDATA%\GamepadLauncherStarter\settings.xml`.
2. Программа прописывается в автозапуск Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
3. Запись `Steam` удаляется из автозапуска Windows (если она указывает на `steam.exe`). Оригинальное значение сохраняется в настройках и в `steam_autostart_backup.txt`. Вернуть можно, сняв галочку «Убрать Steam из автозапуска Windows» и нажав «ОК», либо кнопкой «Вернуть автозапуск Steam».
4. Steam и Epic Games включены, Discord выключен. Если Discord установлен, путь к нему определяется автоматически.
5. Программа остаётся в области уведомлений.

## Настройки

### Вкладка «Общие»

- **Отслеживать подключение геймпада** — главный выключатель.
- **Только трей** — ничего не запускать, только уведомление.
- **Если часть приложений уже запущена** — запускать отсутствующие или ничего не делать.
- **Не реагировать в полноэкранном режиме** — по умолчанию выключено. Если включить, подключение геймпада будет игнорироваться, пока Windows считает активным полноэкранное приложение (игра, видео, Big Picture). Полноэкранные окна самих Steam/Epic/Discord не блокируют запуск. Текущее состояние можно быстро переключить в меню трея.
- **Показывать уведомления в трее** — полное отключение всплывающих сообщений.
- **Запускать программу при входе в Windows**.
- **Запускать приложения, если геймпад уже подключён при старте**.
- **Убрать Steam из автозапуска Windows** и кнопка восстановления.

### Вкладка «Приложения»

Галочка слева включает приложение. Двойной клик открывает настройку. Для каждого приложения можно задать путь, аргументы, имя процесса, режим запуска и поведение, если приложение уже работает.

Чтобы поведение было строгим по исходной задаче («если лаунчеры уже запущены — ничего не делать»), снимите у приложений галочку «Разворачивать окно, если приложение уже запущено». Тогда при повторном подключении геймпада уже работающие приложения не будут даже выводиться на передний план.

### Вкладка «Геймпады»

Показывает подключённые устройства. Снятая галочка добавляет геймпад в список игнорируемых. Кнопка «Симулировать подключение» выполняет тестовый запуск по текущим настройкам.

### Вкладка «Диагностика»

Текущее состояние, пути, процессы, автозапуск, перечисление DirectInput. Можно скопировать отчёт или открыть журнал.

## Проверка работы

1. Закройте Steam и Epic Games (или оставьте — сработает логика «уже запущено»).
2. Убедитесь, что программа запущена и видна иконка в трее.
3. Подключите геймпад по проводу. Включённые приложения должны запуститься.
4. Отключите геймпад. Ничего не должно закрыться.
5. Подключите снова. Вторые копии приложений не создаются. Если включена галочка «Разворачивать окно…», окна уже работающих приложений могут быть показаны; если она выключена — не происходит ничего.
6. Проверьте Bluetooth-подключение.
7. Перезагрузите ПК с подключённым геймпадом — приложения должны запуститься после входа в Windows.

## Если при повторном подключении ничего не происходит

1. Проверьте журнал: `%LOCALAPPDATA%\GamepadLauncherStarter\app.log`.
2. Если в журнале есть строка «Запуск пропущен: активно полноэкранное приложение…», значит включён пропуск в полноэкранном режиме. Отключите его в меню трея («Не реагировать в полноэкранном режиме») или на вкладке «Общие».
3. Если приложения уже запущены, поведение зависит от галочки «Разворачивать окно, если приложение уже запущено» у каждого приложения на вкладке «Приложения».
4. Кнопка трея «Запустить приложения сейчас» запускает выбранные приложения немедленно, без ожидания геймпада.

## Журнал и диагностика

- Журнал: `%LOCALAPPDATA%\GamepadLauncherStarter\app.log` (ротация по 1 МБ).
- Отчёт: `%LOCALAPPDATA%\GamepadLauncherStarter\diagnostics.txt`.
- Команда диагностики:

```powershell
.\dist\GamepadLauncherStarter.exe --diagnose
```

- Открыть настройки при уже запущенной программе: повторный запуск `.exe` или `--settings`.

## Ограничения

- `.exe` не подписан цифровой подписью. SmartScreen может один раз предупредить — это нормально для локально собранной программы.
- Полноэкранный режим определяется средствами Windows; не все borderless-игры распознаются как полноэкранные.
- Режим «свёрнуто» для произвольных приложений означает минимизацию окна. Уход именно в трей зависит от самого приложения; для Steam используется `-silent`.
- Программа работает в сеансе пользователя, а не как служба Windows. Это сделано специально, чтобы запускать приложения в вашем рабочем столе.
- Все изменения реестра ограничены веткой `HKCU` (автозапуск).

## Удаление

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1
```

Скрипт останавливает программу, удаляет её из автозапуска, восстанавливает автозапуск Steam из резервной копии, удаляет ярлык и установленную папку. Настройки и журнал удаляются по подтверждению.
